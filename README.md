# Dev Clothing

A full-featured clothing store website and management system.

## Store Categories

- Men
- Women

## Main Features

- Product browsing
- Product search and filters
- Product variants
- Shopping cart
- Wishlist
- Customer accounts
- Online checkout
- Online payments
- Order tracking
- Product exchange
- Reviews and ratings
- Coupons and offers
- Inventory management
- Customer management
- Admin dashboard
- Sales analytics
- Physical store integration
- AI-powered recommendations

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Payment
- Razorpay

### Version Control
- Git
- GitHub
